## 📌 1. Описание проекта

Проект представляет собой веб-приложение для управления каталогом фильмов.  
Пользователи могут просматривать, искать и добавлять фильмы.

---

## ⚙️ 2. Функциональные возможности

- Регистрация и вход в систему  
- Просмотр списка фильмов  
- Поиск фильмов  
- Добавление фильмов  
- Администрирование  

---

## 👥 3. Сценарии взаимодействия

### Сценарий 1: Регистрация
1. Пользователь открывает страницу регистрации  
2. Вводит email и пароль  
3. Система сохраняет пользователя  

### Сценарий 2: Поиск фильма
1. Пользователь вводит название  
2. Система выполняет SQL-запрос  
3. Отображает результаты  

### Сценарий 3: Добавление фильма
1. Пользователь авторизуется  
2. Переходит на страницу добавления  
3. Заполняет форму  
4. Данные сохраняются в БД  

---

## 🗄️ 4. Структура базы данных

### Таблица movies
| Поле | Тип | Описание |
|------|-----|---------|
| id | int | ID фильма |
| title | varchar | Название |
| description | text | Описание |
| genre | varchar | Жанр |
| rating | float | Рейтинг |
| created_at | datetime | Дата |

### Таблица users
| Поле | Тип |
|------|-----|
| id | int |
| email | varchar |
| password | varchar |

## 💻 6. Примеры кода

### Подключение к БД
```php
$pdo = new PDO("mysql:host=localhost;dbname=movies", "root", "");
```

### Получение фильмов
```php
$top = $pdo->query("SELECT * FROM movies ORDER BY rating DESC LIMIT 6")->fetchAll();
```

1. Что такое PHP?
